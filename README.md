# M SQUARE — متجر الأحذية

موقع متجر أحذية (HTML / CSS / JavaScript بدون أي إطار عمل)، بتصميم مستوحى من هيكل مواقع المتاجر الرياضية:
شريط علوي، قائمة كبيرة (Mega menu)، سلايدر رئيسي، أشرطة منتجات، بانرات، تذييل.

## التصنيفات الأربعة (وهي أيضاً فلاتر التصفية)
| التصنيف | القيم |
|---|---|
| العلامة التجارية | Nike, Adidas, Puma, New Balance, Converse, Vans, Timberland, Skechers |
| الستايل | رياضي، كاجوال، ستريت وير، كلاسيكي، أحذية بوت، صنادل |
| السعر | أقل من 8,000 / 8,000–15,000 / 15,000–25,000 / أكثر من 25,000 دج |
| الفصول | الربيع، الصيف، الخريف، الشتاء (المنتج قد يناسب عدة فصول) |

الفلاتر قابلة للجمع، تُحفظ في الرابط (مثال: `shop.html?brand=nike&season=winter&price=p3`) وتعرض عدد المنتجات لكل خيار.

## الصفحات
- `index.html` — الرئيسية
- `shop.html` — المتجر + التصفية + الترتيب + البحث
- `product.html?id=1` — صفحة المنتج (المقاس، السلة، المفضلة، منتجات مشابهة)

## المزايا
- عربي (RTL) / فرنسي — زر التبديل في الرأس
- سلة ومفضلة محفوظة في المتصفح، ونموذج طلب (الدفع عند الاستلام، 69 ولاية)
- متجاوب مع الهاتف

## تعديل المنتجات
كل البيانات في `js/data.js`:
- `CATEGORIES` — قيم التصنيفات الأربعة
- `PRODUCTS` — المنتجات. لإضافة صورة حقيقية ضع `image: 'assets/products/xxx.jpg'` وإلا يُعرض رسم الحذاء بألوان `colors`.

## التشغيل
افتح `index.html` مباشرة، أو:
```
python3 -m http.server 8000
```


## لوحة الإدارة `/admin` (Supabase)
نفس فكرة متجر Kids of the Future: الطلبات والمنتجات محفوظة في Supabase وتُدار من `admin.html`.

**الطلبات:** إحصائيات، تصفية حسب الحالة، بحث، تغيير الحالة (جديد ← مؤكد ← مشحون ← تم التسليم / رُفض / ملغى)،
اتصال وواتساب بضغطة، نسخ بيانات التوصيل، حظر الأرقام التي ترفض الطلبات، تنبيه صوتي عند وصول طلب جديد، تصدير CSV.

**المنتجات:** إضافة / تعديل / حذف، رفع عدة صور، العلامة والستايل والفصول والمقاسات، السعر والتخفيض، متوفر / نفد، جديد، الأكثر مبيعاً.

### الإعداد (مرة واحدة)
1. في https://supabase.com افتح مشروعاً (يمكن استعمال نفس مشروع Kids of the Future — الجداول هنا تبدأ بـ `ms_` فلا يوجد تعارض).
2. **SQL Editor ← New query**: الصق محتوى `supabase/setup.sql` واضغط **Run**.
3. **Authentication ← Users ← Add user**: أنشئ حساب المدير بالبريد المكتوب في `ADMIN_EMAIL` (إذا لم يكن موجوداً).
4. **Project Settings ← API**: انسخ `Project URL` و `anon public key` وضعهما في `js/config.js`.
5. انشر الموقع، ثم افتح `/admin` وسجّل الدخول.

> الحماية: الزوار يمكنهم إرسال الطلبات فقط، والمدير وحده (حسب البريد) يقرأ الطلبات ويعدّل المنتجات.
> الأسعار والمجموع يعيد حسابها الخادم من جدول المنتجات، فلا يمكن للزبون تغييرها.
> بدون إعداد Supabase يعرض الموقع منتجات `js/data.js` ويحفظ الطلبات في المتصفح فقط.
